- **New app ID, `app.sndscrm`:** this version installs as a new app next to the old SoundScream. Sign in once, then uninstall the old one. Updates from now on install over this one.
- **Less that names the app:** lyrics lookups go out as desktop Chrome, and the sign-in pages no longer see the old app name.
- **Autoplay off stays stopped:** a song that ends with autoplay off goes back to its start and stays paused, even from the lyrics screen. Only the phone that plays the song stops it.

**Install:** download `SoundScream.apk` and install it. It's built for arm64 phones.
